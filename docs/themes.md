# 30 тем для колеса

У каждой темы одинаковый скелет: главная сущность, связанная сущность (1:N) и «фишка» — бизнес-правило для ★★ во 2-й лабе. Поэтому чек-листы общие, а проекты разные.

Правила колеса: выпавшая тема убирается из колеса; у каждого есть один реролл; меняться темами можно по взаимному согласию; свою тему можно предложить, если в ней есть две связанные сущности и фишка.
